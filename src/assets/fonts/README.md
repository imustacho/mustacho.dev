# Social image fonts

Static TrueType versions of the site's DynaPuff (600) and Fredoka (400) fonts,
used by `next/og`, which does not support the site's browser WOFF2 files.
Both fonts are bundled locally; rendering needs no external font requests.

Downloaded from Google Fonts. Their SIL Open Font Licenses are included at
`public/fonts/DynaPuff-OFL.txt` and `public/fonts/Fredoka-OFL.txt`.
